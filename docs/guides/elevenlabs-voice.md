## ElevenLabs Voice & Environment Configurations
- **Vercel Environment Keys**: Dynamic audio features require `ELEVENLABS_API_KEY`. If setting up a new deployment or environment, verify that this key is propagated using Vercel CLI (`vercel env add ELEVENLABS_API_KEY`) to prevent server-side TTS generation failures.
- **Accents & Genders Mapping**: When listing voice models in the settings dropdown, group options using `<optgroup>` corresponding to each of the application's supported selector languages (EN, ES, FR, JA, ZH, AR, HI, PT, DE, IT, KO). Ensure each language group contains both a **Female** and a **Male** voice choice.
- **Robust Voice IDs**: Rely on standard premade voice IDs that exist on all ElevenLabs account tiers (e.g., Rachel `21m00Tcm4TlvDq8ikWAM`, Drew `29vD33N1CtxCmqQRPOHJ`, Clyde `2EiwWnXF2V4j29thjbwy`, Paul `5Q0t7uMcgp8Aagzh1ZQQ`, Adam `pNInz6obpgmx5142qiA7`, Jessica `cgSgspJ2msm6clMCkdW9`, Brian `nPczCjzI2devNBz1zQrb`, Sarah `EXAVITQu4vr4xnSDxMaL`). Avoid custom/private voice IDs that require the API key to have `voices_read` scopes, as production keys are often restricted to write-only text-to-speech access.
- **Stock list lives in `src/lib/voices.ts`** (`ELEVENLABS_VOICE_GROUPS`, re-exported by `app/dashboard/_data.ts`). The server only lets a line speak with a voice on that list or with the account owner's own clone (`effectiveVoiceId`); any other voice ID reads as Rachel.
- **Cloned voices (Pro and Care Team).** The owner reads a script on Greetings & alerts; `api/caregiver/voice-clone` sends the reading (16 kHz WAV, 30 to 130 s) to ElevenLabs instant voice cloning and stores the voice ID in `profiles.settings.customVoice`. This needs the API key's **Voices: Write** permission. Each clone takes one custom-voice slot, so a replaced or removed clone is deleted at ElevenLabs, and so is the clone of an account whose numbers are released (`lib/subscriptionEnd.ts`). If ElevenLabs refuses a clone at call time, `api/twilio/tts` speaks the prompt in Rachel instead.
